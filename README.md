# Simon Says Game

# How to Play

In this game, there are 4 colors and from that colors computer randomly select one color and player needs to click on the same color he/she saw earlier.
At 1st level you have to select only one color.
At 2nd level you have to select color from 1st level and and color selected by computer for 2nd level.
The sequence of color you click must be in sequence they appear else the game is over.

# Advantage of Playing this Game

This game Helps to increase Concentration.
